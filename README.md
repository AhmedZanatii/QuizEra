# 🎓 QuizEra
QuizEra is a modern Web Application built with **ASP.NET Core MVC** designed for managing online quizzes, question banks, and student evaluations efficiently.

## ✨ Features
- **Instructor Dashboard:** Manage courses, topics, and exams seamlessly.
- **Question Bank:** Support for Multiple Choice, True/False, and Essay questions with level-based categorization.
- **Exam Management:** Set exam duration, start/end schedules, and automatic mark calculations.
- **User Management:** Profile customization and avatar uploads.

## 🛠️ Tech Stack
- **Backend:** C# | .NET Core (ASP.NET Core MVC)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Database:** Entity Framework Core | SQL Server
- **Icons:** FontAwesome
